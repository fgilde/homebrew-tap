# fgilde/homebrew-tap

Homebrew formulae for [fgilde](https://github.com/fgilde)'s tools.

```bash
brew install fgilde/tap/quickrun
```

## Formulae

| Formula | What it is |
|---|---|
| [`quickrun`](Formula/quickrun.rb) | [QuickRun](https://github.com/fgilde/QuickRun) — run any git repository with one click |

Formulae here are generated by each project's release workflow and pushed
automatically, so they always match the newest release. Do not edit them by hand;
the next release would overwrite the change.
